How to run the program:
  - Compile: `g++ lib_info.cpp -o lib_info`
  - Run: `./lib_info <filename>`

What the program does:
  This is a program to organize a music library. First, it reads in an unsorted
  list of each song in the music library. It organizes that information internally
  into nested maps, and then once it has all the songs organized, it traverses the
  nested maps to print out the music library in an organized fashion.
